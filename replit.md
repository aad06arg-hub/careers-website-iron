# Careers Website

## Overview
A Flask-based careers website that displays job listings. Users can browse open positions and view job details.

## Project Structure
```
├── app.py              # Main Flask application
├── templates/          # Jinja2 HTML templates
│   ├── base.html       # Base template with header/footer
│   ├── home.html       # Homepage with job listings
│   └── job.html        # Job detail page
├── static/
│   └── style.css       # Stylesheet
├── pyproject.toml      # Python dependencies
└── README.md           # Project readme
```

## Running the Application
The app runs on port 5000 using Flask's built-in development server.
